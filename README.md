# АСУ теплообменника крематория

Система управления теплообменником для отбора тепла отходящих газов крематория и передачи его в сеть отопления.

## Состояние проекта

Сбор исходных данных и разработка требований. Часть оборудования, измерений, режимов и защит уже определена; актуальные решения и оставшиеся вопросы — [DECISIONS.md](DECISIONS.md) и [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md).

По итогам обеих частей сессии 22.10.2026 действуют D-060–D-086: ШТ AIRS NM24 с релейным отключением и фиксируемыми ошибками; переход через ручной ШБ, ручное завершение останова при неисправных концевиках и отдельный возврат питания после ремонта. Уточнены ожидание HMI после перезагрузки, восстановление разрешённой циркуляции, положения ШОД и охлаждение по обязательным расходу/перепаду до закрытия ШТ; повторный пуск — после 10 с непрерывной нормы.

Следующая тема — число повторных пусков охлаждения. Лимит, предупреждение на третьем повторе и правила счётчика не утверждены. Аппаратные схемы, монтаж TUF и проверки остаются открытыми. Программа, HMI, конфигурация оборудования и интеграция этим обновлением не разработаны; испытания не выполнены.
