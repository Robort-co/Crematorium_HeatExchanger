# АСУ теплообменника крематория

Система управления теплообменником для отбора тепла отходящих газов крематория и передачи его в сеть отопления.

## Состояние проекта
Сбор исходных данных и разработка требований.
Оборудование, датчики, исполнительные механизмы и защитные алгоритмы пока не определены.
