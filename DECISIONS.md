# Решения проекта

Актуализировано 2026-10-09. Прежние решения и история от 2026-10-06 и 2026-10-08 сохранены. ## Неутверждённые предложения

- Резервирование питания ПР205 и удалённый WB-MCM8HV не утверждены.
- УЗМ-3-63К вместо контакторов не принят в действующую схему; по D-041 для каждого насоса сохраняется контактор.
- Контроль залипания как законченный алгоритм не утверждён; фазные DI не доказывают причину неисправности.
- ПРМ-220.1 и три реле на насос переведены из предложений в утверждённую схему D-039/D-041, с шестью отдельными DI.
- Прежние предложения питания WB от резервированных 24 В и настроек WB относятся к историческому варианту D-015, исключённому D-041.

- Резервируемое питание.
- Поведение при пропадании силовой сети.
- Защита двигателей.
- Трактовка календарного периода «2 месяца».
- Допустимые состояния устройств при останове.
- Обход запретов пуска не утверждён; запрещённый пуск отклоняется по D-027.
- Базовый перепад для диагностики ухудшения.
- Неописанные переходы ШОД и остальные неразобранные функции; см. уточнённые вопросы ниже.

## 3. Изменённые или отменённые прежние решения

| Прежний вариант | Окончательное решение |
|---|---|
| Сначала остановить насосы, затем закрывать ШТ | **Сначала открыть ШБ, затем закрыть ШТ, только потом останавливать насосы** |
| Останов завершён после закрытия ШТ | Завершён после выключения насосов и выдачи команд затворам |
| Отмена после подтверждения ШБ не предусмотрена | Разрешена во время ожидания закрытия ШТ, только при достоверно открытом ШТ |
| Рабочий контроль открытого ШТ действует в процессе его штатного закрытия | На этом этапе заменяется контролем закрытия за 60 секунд |
| Выдержки рабочего контроля ШТ 10 секунд | **5 секунд** |
| Давление: выдержка 5 секунд | **3 секунды** |
| Гистерезис давления 0,1 бар | **0,2 бар** |
| Любой одиночный отказ датчика воды некритический | Потеря единственного/всех датчиков подачи — **критическая** |
| Восстановление одного датчика давления разрешает пуск | Для пуска нужны **оба исправных датчика** |
| ΔT снимается сразу или на пороге 20 °C | Отдельный порог **19 °C**, выдержка **10 секунд**; оба порога настраиваемые |
| Поправка ШОД только для отображения | Применяется также к диагностическому сигналу |
| K по умолчанию 1,0 | **1,2** |
| Диагностика ШОД 10 секунд | **5 секунд**, с настройкой 2–15 секунд |
| Всплывающее предупреждение о движении ШОД | Только значок на мнемосхеме |
| Диагностика движения в обычном ручном режиме | Отключена; исключение — автоматическое охлаждение и закрытие после него |
