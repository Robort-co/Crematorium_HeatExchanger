## 3. Допущения и границы метода

1. Тракт полностью заполнен однофазной водой; газовые включения и кипение не моделируются.
2. Для коротких труб приняты гидравлически гладкие стенки, абсолютная шероховатость 0. Это расчётное допущение, не обмер металла.
3. Каждый температурный вариант изотермический. Вязкостная поправка стенки φ = 1; тепловой профиль не рассчитывался.
4. Рассмотрены 20, 40, 60 и 80 °C. Это точки чувствительности, не уставки, не подтверждённый рабочий диапазон и не замена ранее сообщённого предела 85 °C перед насосами.
5. Для межтрубной полости применена приближённая зависимость Керна с суммированием по отсекам различного шага. Это инженерное расширение упрощённого метода; точность для данной компоновки отдельно не проверена.
6. Потоки через зазоры труба–перегородка и перегородка–обечайка, обход пучка и взаимодействие входной струи с трубами отдельно не разрешаются. Принятие STEP не делает оценку точным расчётом течения.
7. Переход из трубы в большую полость принят с ζ = 1, из полости в трубу с острой кромкой — ζ = 0,5. На пару вход/выход Ø100 принято Σζ = 1,5; такое же приближение использовано для трубы Ø261. Это коэффициенты идеализации, не измерения данного ТО.

Методическая погрешность не определена. Температурный диапазон результатов не является доверительным интервалом полного расчёта.

## 4. Формулы и свойства воды

Q — м³/ч; q = Q/3600 — м³/с; g = 9,80665 м/с².

Для шахматной ячейки Pt = 0,080 м, Pr = 0,070 м, do = 0,057 м:

    De = 4 × (Pt × Pr − π × do² / 4) / (π × do) = 0,0680902 м.

Для отсека шириной B, при Ds = 0,810 м:

    A = B × Ds × (Pt − do) / Pt
    u = q / A
    Re = ρ × u × De / μ
    fK = exp(0,576 − 0,19 × ln(Re))
    Δp_отсека = fK × Ds / De × ρ × u² / 2

Межтрубная потеря — сумма по семи отсекам. Корреляция fK дана для 400 < Re < 10⁶; рассмотренные точки 10–40 м³/ч и 20–80 °C внутри этого диапазона. Это проверка Re, не полной применимости метода к конструкции.

Для патрубков и перемычки:

    vD = q / (π × D² / 4)
    Δp_местные = Σζ × ρ × vD² / 2
    Δp_трение = λ × L / D × ρ × vD² / 2
    1 / sqrt(λ) = −2 × log10(2,51 / (ReD × sqrt(λ)))

Последняя формула — уравнение Кольбрука для коэффициента Дарси и принятой нулевой шероховатости.

    ΔpТО = Δp_межтрубная + Δp_местные100 + Δp_местные261 + Δp_трение
    hТО = ΔpТО / (ρ × g)

## 6. Использование в расчёте сети

Характеристика одного пассивного элемента не определяет рабочую точку насоса и направление в открытой межзданной обратке. Нужны напорные характеристики насосов, сопротивления остальных ветвей и проверенная топология.

При рассматриваемых направлениях расход через ТО складывается из суммарного расхода четырёх местных потребителей крематория и расхода, уходящего в котельную. Равенство расхода через ТО и межзданного расхода не предполагается.

В данной модели сопротивление самого ТО мало. Сопротивление насосной группы, фильтров и арматуры из этого не следует. Новые защиты или уставки на основании записки не согласованы.

## 8. Воспроизводимый расчёт

Python 3, стандартная библиотека. Код — часть расчётной записки, не программа контроллера или конфигурация оборудования. При запуске только печатает результаты.

~~~python
import math

G = 9.80665
DS, DO, PT, PR = 0.810, 0.057, 0.080, 0.070
DE = 4 * (PT * PR - math.pi * DO**2 / 4) / (math.pi * DO)
BAYS = (0.400, 0.550, 0.551, 0.450, 0.400, 1.104, 0.450)
AREAS = tuple(b * DS * (PT - DO) / PT for b in BAYS)
WATER = {
    20: (998.2, 1.0016e-3),
    40: (992.2, 0.6527e-3),
    60: (983.2, 0.4660e-3),
    80: (971.8, 0.3540e-3),
}

def smooth_darcy(re):
    f = 0.02
    for _ in range(30):
        f = 1 / (-2 * math.log10(2.51 / (re * math.sqrt(f))))**2
    return f

def pressure_loss(q_m3h, temperature):
    if not 10 <= q_m3h <= 40:
        raise ValueError("This estimate was checked for 10-40 m3/h only")
    rho, mu = WATER[temperature]
    q = q_m3h / 3600
    shell = 0.0
    for area in AREAS:
        velocity = q / area
        re = rho * velocity * DE / mu
        if not 400 < re < 1e6:
            raise ValueError("Outside the selected Kern correlation range")
        fk = math.exp(0.576 - 0.19 * math.log(re))
        shell += fk * DS / DE * rho * velocity**2 / 2

    v100 = q / (math.pi * 0.100**2 / 4)
    v261 = q / (math.pi * 0.261**2 / 4)
    nozzle = 1.5 * rho * v100**2 / 2
    link = 1.5 * rho * v261**2 / 2
    short_pipes = 0.0
    for diameter, length, velocity in (
        (0.100, 0.310, v100),
        (0.261, 0.290, v261),
    ):
        re = rho * velocity * diameter / mu
        short_pipes += (
            smooth_darcy(re) * length / diameter * rho * velocity**2 / 2
        )
    total = shell + nozzle + link + short_pipes
    return {
        "pressure_Pa": total,
        "head_m": total / (rho * G),
        "shell_Pa": shell,
        "nozzle_Pa": nozzle,
        "link_Pa": link,
        "pipe_friction_Pa": short_pipes,
    }

for q in (10, 20, 30, 40):
    variants = [pressure_loss(q, t) for t in WATER]
    p_min = min(v["pressure_Pa"] for v in variants) / 1000
    p_max = max(v["pressure_Pa"] for v in variants) / 1000
    at60 = pressure_loss(q, 60)
    print(
        f"Q={q:2d} m3/h; dp={p_min:.4f}-{p_max:.4f} kPa; "
        f"dp60={at60['pressure_Pa']/1000:.4f} kPa; "
        f"h60={at60['head_m']:.5f} m"
    )
print("Breakdown at Q=20 m3/h, T=60 C:", pressure_loss(20, 60))
~~~
