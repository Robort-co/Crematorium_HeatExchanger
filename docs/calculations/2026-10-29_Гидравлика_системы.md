### 3.5. Усреднённая оценка магистралей и радиаторов одного этажа

По запросу пользователя расчёт выполняется без индивидуальных подводок и внешней арматуры. Допущения: вода 60 °C, гладкие магистрали ПП Dвн25; 10 одинаковых радиаторов Base 500 по 10 секций; равномерные участки магистралей по 5 м и расход каждого прибора q = Q/10. В участках каждой магистрали расходы составляют Q/10, 2Q/10, …, Q. Потери вычислены по Darcy–Weisbach/Colebrook для каждого участка. Средняя по десяти путям потеря в магистралях:

    hср,трубы(Q) = 2 · Σ[k=1…10] (k/10) · hтрубы(5 м, Dвн25, kQ/10)

## 4. Баланс и направления потоков

Обозначения: R — общая обратка крематория перед местной группой ТО; S — общая подача крематория; U/L — верхний/нижний узлы гидрострелки.

Рабочая топология, использованная в обсуждении:

- R → насос ТО → ТО → S.
- S → четыре параллельные ветви с Oasis и потребителями → R.
- S → межзданная подача → Э2 → котловой насос → U.
- U → параллельно гидрострелка и два цеховых контура → L.
- L → водяной тракт ТТ50 → Э3 → межзданная обратка → R.
- Прямая связь обратного коллектора котельной с межзданной обраткой закрыта.

Это топология расчётного сценария, не монтажная исполнительная схема. Подтверждены назначение Э4, закрытие прямого возврата и открытый маршрут через ТТ50/Э3. Позднее при создании HTML пользователь прямо подтвердил Э1 как прямой путь от выхода ТТ50 к всасыванию котловых насосов, Э2 — подключение подачи крематория к этому всасыванию; фиксированные положения сохранены.

При положительных направлениях, заданных выше, для установившегося несжимаемого потока:

    QТО = Qместные + Qмеж
    Qместные = q1 + q2 + q3 + q4
    Qмеж = Qкотлового насоса = Qчерез ТТ50
    Qпрямой обратки = 0
    Qгидрострелки (сверху вниз) = Qмеж − Qцех1 − Qцех2

Последнее значение может оказаться отрицательным; тогда внутри гидрострелки результирующий поток направлен снизу вверх. Превышение котлового расхода над суммой цеховых для этого сценария не принято заранее.

Расходы насосов не складываются механически. Насос ТО и котловой насос действуют в общей внешней петле, но расход через ТО больше на расход местных потребителей.

### Уравнения численной модели

ΔHк — разность пьезометрических напоров S и R; ΔHс — разность U и L. Hнасоса(Q) — его напорная характеристика; h(Q) — потери соответствующего участка:

    ΔHк = HнасосаТО(QТО) − hТО(QТО) − hобщих труб(QТО) − hдоптрубТО(QТО)
    hместной ветви_i(qi) = ΔHк + HOasis_II(qi)
    hцех_j(Qцех_j) = ΔHс + HVALFEX_III(Qцех_j)
    ΔHс = hгидрострелки(Qмеж − Qцех1 − Qцех2)
    ΔHк + Hкотлового насоса(Qмеж) =
        hмежзданных труб(Qмеж) + hТТ50(Qмеж) + hдоптрубкотельной(Qмеж) + ΔHс

По последнему указанию пользователя слагаемые местных потерь в арматуре/поворотах отсутствуют. hдоптрубТО и hдоптрубкотельной означают только трение в дополнительных прямых участках, если они не вошли в уже заданные длины; двойной учёт длин недопустим. Такие дополнительные участки не заданы и в первой модели не включены. Потери коллекторов и гидрострелки явно исключены пользователем: ΔHс = 0. Поэтому расходы цеховых ветвей в этой идеализации определяются собственными насосами и сопротивлениями, а разность с Qмеж проходит через гидрострелку.

Первая численная оценка получена с аналогами §3.6 и допущениями §3.7; результаты и проверка границ — §10. Достаточность этой модели для расчёта тепловых нагрузок, аварийных режимов или настройки защит не установлена.

- Подводки, внешняя арматура, коллекторы и гидрострелка исключены по указанию пользователя. Неизвестные дополнительные прямые участки не включены; их возможное влияние не оценено. Эти упрощения не доказывают отсутствие фактических потерь.
- Расчёт выполнен при 60 °C и заданных положениях арматуры. Температурное распределение, тепловая мощность, режим горелки, кавитация, пусковые переходы и аварийные режимы не рассчитаны.

## 8. Повторение расчёта труб и ветвей Ballu

Python 3, стандартная библиотека. Код только выводит таблицы; это не код АСУ.

~~~python
import math

RHO, MU, G = 983.2, 0.000466, 9.80665

def pipe_loss(q_m3h, length_m, diameter_m, roughness_m=0.0):
    velocity = (q_m3h / 3600) / (math.pi * diameter_m**2 / 4)
    reynolds = RHO * velocity * diameter_m / MU
    if reynolds <= 4000:
        raise ValueError("This calculation uses turbulent-flow points only")
    friction = 0.02
    for _ in range(30):
        friction = (
            -2 * math.log10(
                roughness_m / (3.7 * diameter_m)
                + 2.51 / (reynolds * math.sqrt(friction))
            )
        )**-2
    head = friction * length_m / diameter_m * velocity**2 / (2 * G)
    return velocity, head

cases = (
    ("PP25 constant-flow reference / Ballu pipes", 100, 0.025, (1, 1.5, 1.8, 2, 2.5, 3)),
    ("interbuilding", 140, 0.065, (5, 8, 10, 12, 15, 20)),
    ("workshop long", 140, 0.065, (3, 5, 7, 9.6)),
    ("workshop short", 40, 0.040, (2, 3, 4, 5, 6.9)),
    ("HX shared steel", 40, 0.100, (10, 20, 30, 40)),
)
for name, length, diameter, flows in cases:
    print(name)
    for q in flows:
        v, h = pipe_loss(q, length, diameter)
        print(f"Q={q:g} m3/h; v={v:.3f} m/s; h={h:.3f} m")
print("Steel roughness scenario: 0.05 mm")
for q in (10, 20, 30, 40):
    print(q, pipe_loss(q, 40, 0.100, 0.00005))

# Ballu manual p. 23, water 70/50 C: all 15 Q [m3/h], dP [kPa] pairs.
BALLU_Q_DP60 = sorted([
    (2.174, 7.1), (1.982, 6.0), (1.784, 5.0), (1.586, 4.0), (1.385, 3.1),
    (1.730, 4.7), (1.576, 4.0), (1.419, 3.3), (1.262, 2.6), (1.104, 2.1),
    (1.530, 3.7), (1.394, 3.2), (1.256, 2.6), (1.119, 2.1), (0.979, 1.7),
])

def ballu_loss(q_m3h):
    for (qa, pa), (qb, pb) in zip(BALLU_Q_DP60, BALLU_Q_DP60[1:]):
        if qa <= q_m3h <= qb:
            dp_kpa = pa + (pb - pa) * (q_m3h - qa) / (qb - qa)
            return dp_kpa, dp_kpa * 1000 / (RHO * G)
    raise ValueError("Outside tabulated Ballu 70/50 C flow range")

print("Each Ballu branch, fitting losses omitted by user instruction")
for q in (1, 1.5, 2):
    dp_kpa, h_heater = ballu_loss(q)
    _, h_pipe = pipe_loss(q, 100, 0.025)
    print(f"Q={q:g}; Ballu={dp_kpa:.3f} kPa; "
          f"pipes={h_pipe:.3f} m; heater={h_heater:.3f} m; "
          f"total={h_pipe+h_heater:.3f} m")
~~~

## 9. Повторение усреднённой оценки радиаторных этажей

Выполняется после кода §8, использует те же `pipe_loss`, `RHO`, `G`. Расчёт проверяет среднее по десяти путям, но не решает фактическое распределение расходов между радиаторами.

~~~python
for q in (1.5, 2.0, 2.5, 3.0):
    n = 10
    losses = [pipe_loss(q*k/n, 5, 0.025)[1] for k in range(1, n+1)]
    paths = [sum(losses[n-i-1:]) + sum(losses[i:]) for i in range(n)]
    h_mean_pipe = 2*sum(losses[k-1]*k/n for k in range(1, n+1))
    assert abs(sum(paths)/n - h_mean_pipe) < 1e-12
    mass_kg_h = RHO*q/n
    assert 60 <= mass_kg_h <= 360
    h_radiators = []
    for s60, s360 in ((31800, 23900), (14500, 8400)):
        s = s60 + (s360-s60)*(mass_kg_h-60)/300
        h_radiators.append(s*(mass_kg_h/3600)**2/(RHO*G))
    h_low = h_mean_pipe + min(h_radiators)
    h_high = h_mean_pipe + max(h_radiators)
    print(f"Q={q:g}; mean pipes={h_mean_pipe:.6f} m; "
          f"mean total={h_low:.6f}..{h_high:.6f} m; "
          f"mean pressure={h_low*RHO*G/1000:.6f}.."
          f"{h_high*RHO*G/1000:.6f} kPa; "
          f"pipe paths={min(paths):.6f}..{max(paths):.6f} m")
~~~

### Чувствительность и границы

1. **Размещение трёх цеховых Ballu.** Если вместо общего участка с полным расходом принять равномерные распределительные магистрали из трёх частей с равными отборами, усреднённый расход длинной ветви получается 9,02 вместо 8,53 м³/ч; по 3,01 вместо 2,84 на прибор. Гидрострелка тогда пропускает вниз 10,76 м³/ч. Это два условных варианта трассы, не гарантированный диапазон объекта. В идеальной гидрострелке изменение этой ветви не меняет Qмеж.
2. **Напор аналога ТО.** При умножении всей выбранной кривой H(Q) на 0,8 модель даёт QТО = 35,07; Qмеж = 23,42; каждый этаж = 3,72; каждый местный Ballu = 2,11 м³/ч. Это заданная вариация, не паспортный допуск и не нижняя граница реального ROMMER.
3. **Верхняя граница кривой местного аналога.** Базовые 3,94 м³/ч на этаж уже близки к последней считанной точке UPS 25-60 II — 4,0 м³/ч. Увеличение кривой ТО приблизительно на 5,9% достигает этой границы. При сценарии +20% решение требует расхода этажа за пределами кривой; такой результат не вычислялся экстраполяцией и не заменялся искусственным ограничением расхода 4,0. Надёжного верхнего диапазона фактических расходов эта модель не даёт.
4. **Экстраполяция Ballu.** Условное изменение его расчётных потерь на −30% / +30% даёт длинной цеховой ветви 8,84 / 8,25 м³/ч, короткой 4,88 / 4,20 м³/ч. QТО меняется примерно от 36,63 до 36,55 м³/ч. Эти проценты выбраны для проверки чувствительности, не являются оценкой погрешности производителя. Нельзя из небольшого изменения QТО заключать, что расход отдельного Ballu установлен точно.
5. **Радиаторные этажи.** Средний путь и назначенные равные расходы приборов сохранены по запросу усреднения. Полное распределение по петле не решено. Близость к границе кривой Oasis делает дальнейшую замену среднего пути без повторной проверки недопустимой.
6. **Оставшиеся допущения.** Шероховатость стали, неизвестные дополнительные прямые участки, точная характеристика ROMMER, другого котлового насоса и фактического Oasis, направление/исполнение ТТ50 и расширение кривой приборов не подтверждены измерениями. Нулевые потери исключённых элементов могут завышать расходы; общая погрешность с учётом насосов неизвестна.

### Воспроизведение решения

Самостоятельный Python 3, только стандартная библиотека. Код выводит базовое решение, варианты и проверяет балансы; не обращается к оборудованию и не меняет файлы. Названия кривых `hx` и `oasis` в коде обозначают **аналоги из §3.6**, а не оцифрованные характеристики ROMMER/Oasis. Интерполяция насосов ограничена считанными диапазонами; расширение потерь приборов описано в §3.7.

~~~python
import math
RHO, MU, G = 983.2, 0.000466, 9.80665
CURVES = {
 "hx": [(0,10.7),(10,10.0),(20,9.2),(25,8.4),(30,7.4),(35,6.0),(40,4.5),(45,2.6),(50,0.5),(51,0)],
 "boiler": [(0,6.2),(5,5.7),(10,5.2),(15,4.4),(20,3.2),(25,1.7),(30,0)],
 "oasis": [(0,5.3),(.5,4.7),(1,3.9),(1.5,3.1),(2,2.4),(2.5,1.85),(3,1.4),(3.5,1.0),(4,.7)],
 "vf32": [(0,8.2),(2,6.8),(4,5.4),(6,4.0),(8,2.6),(9.6,1.4)],
 "vf25": [(0,8.2),(2,6.2),(4,4.2),(6,2.2),(6.8,1.4)],
}
def interp(q, pts):
 if not pts[0][0] <= q <= pts[-1][0]:
  raise ValueError(f"Outside source range: {q} not in {pts[0][0]}..{pts[-1][0]}")
 for (x,y),(xx,yy) in zip(pts,pts[1:]):
  if x<=q<=xx: return y+(yy-y)*(q-x)/(xx-x)
def ph(q,L,D):
 if q==0:return 0.
 v=q/3600/(math.pi*D*D/4)
 re=RHO*v*D/MU
 if re<2300: f=64/re
 else:
  ft=.02
  for _ in range(20): ft=(-2*math.log10(2.51/(max(re,4000)*math.sqrt(ft))))**-2
  f=ft if re>=4000 else (64/2300)*(4000-re)/1700+ft*(re-2300)/1700
 return f*L/D*v*v/(2*G)
BALLU=[(.979,1.7),(1.104,2.1),(1.119,2.1),(1.256,2.6),(1.262,2.6),(1.385,3.1),(1.394,3.2),(1.419,3.3),(1.530,3.7),(1.576,4),(1.586,4),(1.730,4.7),(1.784,5),(1.982,6),(2.174,7.1)]
xs=[math.log(x) for x,y in BALLU]; ys=[math.log(y) for x,y in BALLU]
xm=sum(xs)/len(xs); ym=sum(ys)/len(ys)
EXP=sum((x-xm)*(y-ym) for x,y in zip(xs,ys))/sum((x-xm)**2 for x in xs)
COEF=math.exp(ym-EXP*xm)
def ballu(q):return 1000*COEF*q**EXP/(RHO*G)
def rad(q):
 mass=RHO*q/10
 m=min(360,max(60,mass))
 s=31800+(23900-31800)*(m-60)/300
 return s*(mass/3600)**2/(RHO*G)
def mean_pipes(q,n,L,D):
 return 2*sum(k/n*ph(k*q/n,L/n,D) for k in range(1,n+1))
def floor(q):return mean_pipes(q,10,50,.025)+rad(q)
def crem_ballu(q):return ph(q,100,.025)+ballu(q)
def bisection(fn,lo,hi):
 a,b=fn(lo),fn(hi)
 if a*b>0:raise ValueError(f"No root bracket {lo}..{hi}: {a},{b}")
 for _ in range(60):
  mid=(lo+hi)/2; c=fn(mid)
  if a*c<=0:hi=mid
  else:lo=mid;a=c
 return (lo+hi)/2
def pump(name,q):return interp(q,CURVES[name])
def inter(dh):
 return bisection(lambda q:ph(q,140,.065)+2.2*q*q/(RHO*G)-pump("boiler",q)-dh,0,30)
def hxloss(q):
 return interp(q,[(0,0),(10,.01111),(20,.04378),(30,.09771),(40,.17278)])
def solve(scale=1.0,pipe_factor=1.0):
 def locals_at(dh,typ):
  loss=lambda q:(pipe_factor*mean_pipes(q,10,50,.025)+rad(q)) if typ=="rad" else crem_ballu(q)
  return bisection(lambda q:loss(q)-pump("oasis",q)-dh,0,4)
 def quantities(dh):
  qr=locals_at(dh,"rad"); qb=locals_at(dh,"ballu"); qi=inter(dh)
  return qr,qb,qi,2*qr+2*qb+qi
 dh_max=pipe_factor*mean_pipes(4,10,50,.025)+rad(4)-pump("oasis",4)
 def eq(dh):
  qt=quantities(dh)[3]
  return scale*pump("hx",qt)-hxloss(qt)-ph(qt,40,.1)-dh
 f0=eq(0); f1=eq(dh_max)
 if f0*f1>0:
  return {"unsupported":True,"dh_boundary":dh_max,"residual":f1,"boundary":quantities(dh_max)}
 dh=bisection(eq,0,dh_max)
 qr,qb,qi,qt=quantities(dh)
 return {"dh":dh,"qrad_each":qr,"qballu_each":qb,"qinter":qi,"qtotal":qt,
 "residual_m":eq(dh),"mass_residual":qt-(2*qr+2*qb+qi),
 "rad_kg_h":RHO*qr/10}
def shop(n,L,D,name,distributed):
 def loss(q):
  hp=mean_pipes(q,n,L/2,D) if distributed else ph(q,L,D)
  return hp+ballu(q/n)
 return bisection(lambda q:loss(q)-pump(name,q),0,CURVES[name][-1][0])
print("BALLU fit",COEF,EXP,"max relative residual",max(abs(COEF*q**EXP/p-1) for q,p in BALLU))
for scale in (.8,1,1.2):
 try: print("MAIN SCALE",scale,solve(scale))
 except ValueError as e: print("MAIN SCALE",scale,"INVALID",str(e))
for name,n,L,D in [("vf32",3,140,.065),("vf25",1,40,.040)]:
 for distributed in ([False,True] if n==3 else [False]):
  q=shop(n,L,D,name,distributed)
  print("SHOP",name,"distributed",distributed,"total",q,"each",q/n,"head",pump(name,q))

base = solve()
assert not base.get("unsupported", False)
dh, qr, qb, qi, qt = (base[k] for k in
    ("dh", "qrad_each", "qballu_each", "qinter", "qtotal"))
ql = shop(3, 140, .065, "vf32", False)
qs = shop(1, 40, .040, "vf25", False)
qsep = qi - ql - qs
residuals = [
    qt - 2*qr - 2*qb - qi,
    qi - ql - qs - qsep,
    pump("hx", qt) - hxloss(qt) - ph(qt, 40, .1) - dh,
    floor(qr) - pump("oasis", qr) - dh,
    crem_ballu(qb) - pump("oasis", qb) - dh,
    ph(qi, 140, .065) + 2.2*qi*qi/(RHO*G) - pump("boiler", qi) - dh,
    ph(ql, 140, .065) + ballu(ql/3) - pump("vf32", ql),
    ph(qs, 40, .040) + ballu(qs) - pump("vf25", qs),
]
assert max(abs(r) for r in residuals) < 1e-8
print("CHECKS", max(abs(r) for r in residuals), "separator_down", qsep)
original_ballu = ballu
for factor in (.7, 1.3):
    def ballu(q):
        return factor * original_ballu(q)
    print("BALLU factor", factor, solve(),
          "shops", shop(3, 140, .065, "vf32", False),
          shop(1, 40, .040, "vf25", False))
ballu = original_ballu
~~~
