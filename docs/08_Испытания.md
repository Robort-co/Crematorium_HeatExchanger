# Испытания

## Основание и статус

Актуализировано 2026-10-06 по D-001, D-004–D-016 в [DECISIONS.md](../DECISIONS.md). Ниже — перечень проверок согласованных требований, а не отчёт об испытаниях. Все проверки имеют статус «не выполнено». Программного кода для испытаний пока нет.

Проверки не утверждают новые защитные действия. Методы воспроизведения отказов, состав стенда, условия допуска и участники требуют отдельного определения; натурные аварийные испытания этим документом не назначаются.

## Документальная проверка оборудования и I/O

| Проверка | Ожидаемое соответствие |
| --- | --- |
| Комплект контроллеров | ПР205-24.1211.02.2.0 и ПРМ-220.3; наличие подтверждено исходными данными |
| Подключение температур | PT1000 к ПР205, термопары к ПРМ-220.3; каналы сверить после итоговой раскладки |
| ШТ | Ручной, два концевика; по одному DI «Открыто» и «Закрыто», без прежних аналоговых команд и обратной связи |
| Насосная группа | Одинаковые насосы фиксированной скорости; затворы после насосов; по фильтру перед насосом в каждой ветви |
| Гидравлические измерения | Два одинаковых датчика 0–4 бар на общих тройниках; расходомер вне насосной группы, положение между точками давления не подтверждено; труба 108×4 мм |
| Сеть | Новатек РНПП-311М-24 на общем вводе, отдельный изолированный БП 24 В, один DI состояния |
| WB-MAP3EV | Два устройства; не подменять проверкой неутверждённые пороги/защиты |

Баланс I/O и назначение клемм сверять только после утверждения соответствующей схемы.

## Проверка режимов, команд и насосной группы

| Сценарий | Критерий по согласованному требованию |
| --- | --- |
| Пуск | Принимается с HMI или ARANGA по согласованному впоследствии интерфейсу |
| Конкурирующие штатные команды | Приоритет «Пуск»; не обходить защиты. Конкретную методику определить после детализации команд |
| Остановленное состояние по умолчанию | Оба насоса выключены, оба затвора открыты |
| Настройки останова | Положения задаются в меню; проверяемый перечень допустимых состояний ещё открыт |
| Штатный останов | Сначала подтверждение ШБ и достоверное закрытие ШТ по D-028, затем закрытие затвора рабочего насоса → выключение насоса → команды на положения останова |
| Ручная смена при работе | Разрешена; последовательность X→Y: включение Y, закрытие затвора X, отложенное открытие Y, выключение X по закрытию либо таймауту |
| Задержка открытия | От команды включения нового насоса; диапазон 0–5 с, значение по умолчанию 1 с; проверить границы после реализации |
| Плановая смена | По истечении периода выполняется при следующем запуске; отдельного предварительного подтверждения оператора нет |
| Календарный период | По умолчанию 1 неделя; нижняя граница 1 день; верхняя «2 месяца» — методика проверки после уточнения трактовки |
| Отключённое чередование | Плановое автоматическое чередование отключено |
| Ручная смена | Календарный период начинается заново |
| Аварийная смена | Автоматическое чередование отключается, выдаётся сообщение |
| Сообщение после смены | Точный текст: «Была произведена смена насоса! Проверьте гидравлический узел насосной группы» |
| ОК сообщения | Закрывает сообщение; не является разрешением на пуск |
| Наработка | Отдельные счётчики двух насосов и теплообменника, возможность сброса; критерии накопления и права сброса ещё уточняются |

Проверка исключения прежних решений: нет чередования по разности наработки, часовой уставки этой разности, универсального закрытия обоих затворов перед любой сменой и разрешения запуска через ОК сообщения.

## Проверка диагностики и таймаутов

| Сценарий | Ожидаемое действие |
| --- | --- |
| Нет подтверждения закрытия за 40 с | Насос выключается, предупреждение |
| Нет подтверждения открытия за 40 с | Насос остаётся включённым; смена только по этой причине требует подтверждения оператора |
| Появление соответствующего концевика | Если автоматическое квитирование реализовано, оно допускается для соответствующего предупреждения |
| Низкий перепад и низкий расход | Диагностика неисправности насоса/затвора и аварийная смена; не добавлять несогласованную выдержку |
| Низкий перепад при сохраняющемся расходе | Предупреждение о возможной проблеме измерения давления |
| Переключение насосов | Отклонение перепада не считается аварией |
| Подтверждение открытия затвора | Контроль возобновляется через 5 с |
| Нет подтверждения открытия | Контроль остаётся отключённым; не распространять это автоматически на все защиты |
| Настройки минимального перепада | По умолчанию 0,3 бар; диапазон 0,1–2 бар |
| Настройки минимального расхода | По умолчанию 5 м³/ч; диапазон 1–42 м³/ч |
| Постепенное ухудшение | Порог по умолчанию 30%, диапазон 5–50%, выдержка 60 с; полная проверка после определения базового перепада и реакции |

Границы отключаемой диагностики и обработка недостоверных данных уточняются до завершения программы испытаний.

## Связь, расчёты и восстановление

- Ручной режим дымососа: ввод задания частоты в Гц; сквозной: ARANGA → ПР205 → ПЧ, регулятор тяги в ARANGA.
- Расход поступает по Modbus. Проверка адресов и форматов возможна после согласования карты; регистры для испытаний не изобретаются.
- Тепловая мощность рассчитывается в контроллере; эталонные значения и допуски определить после утверждения методики расчёта.
- Внешние статусы, права сброса счётчиков и сообщения проверяются только в объёме утверждённого [INTEGRATION_INTERFACE.md](../INTEGRATION_INTERFACE.md).
- После восстановления питания — обычная последовательность, без прежнего «просто продолжаем». Разрешение повторного пуска и реакция на пропадание силовой сети ещё открыты.
- Методики потери связи требуют детализации; проверки утверждённых функций ШОД добавлены ниже.

## Протокол и незавершённые вопросы

В будущем протоколе фиксировать требование/решение, версию реализации, условия, входные воздействия, ожидаемый и фактический результат, дату, исполнителя и замечания. Результатов испытаний пока нет.

Не определены итоговый I/O, силовая аппаратура, контроль залипания, резервирование, защита двигателей, «2 месяца», допустимые состояния останова, обход запретов не утверждён, базовый перепад, неописанные переходы ШОД и остальные неразобранные функции, точные обозначения оборудования. Новые критерии для них не назначаются.
