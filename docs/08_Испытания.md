Проверка исключения прежних решений: нет чередования по разности наработки, часовой уставки этой разности, универсального закрытия обоих затворов перед любой сменой и разрешения запуска через ОК сообщения.

## Проверка диагностики и таймаутов

| Сценарий | Ожидаемое действие |
| --- | --- |
| Нет подтверждения закрытия за 45 с | Насос выключается, предупреждение |
| Нет подтверждения открытия за 45 с | Насос остаётся включённым; смена только по этой причине требует подтверждения оператора |
| Появление соответствующего концевика | Если автоматическое квитирование реализовано, оно допускается для соответствующего предупреждения |
| Низкий перепад и низкий расход при включённом учёте расхода | Диагностика неисправности насоса/затвора и аварийная смена; не добавлять несогласованную выдержку |
| Низкий перепад при сохраняющемся расходе и включённом учёте расхода | Предупреждение о возможной проблеме измерения давления |
| Переключение насосов | Отклонение перепада не считается аварией |
| Подтверждение открытия затвора | Контроль возобновляется через 5 с |
| Нет подтверждения открытия | Контроль остаётся отключённым; не распространять это автоматически на все защиты |
| Настройки минимального перепада | По умолчанию 0,3 бар; диапазон 0,1–2 бар |
| Настройки минимального расхода | По умолчанию 5 м³/ч; диапазон 1–42 м³/ч |
| Постепенное ухудшение | Порог по умолчанию 30%, диапазон 5–50%, выдержка 60 с; полная проверка после определения базового перепада и реакции |

Границы отключаемой диагностики и обработка недостоверных данных уточняются до завершения программы испытаний.

## Связь, расчёты и восстановление

- Ручной режим дымососа: ввод задания частоты в Гц; сквозной: ARANGA → ПР205 → ПЧ, регулятор тяги в ARANGA.
- Расход поступает по Modbus. Проверка адресов и форматов возможна после согласования карты; регистры для испытаний не изобретаются.
- Тепловая мощность рассчитывается в контроллере; эталонные значения и допуски определить после утверждения методики расчёта.
- Внешние статусы, права сброса счётчиков и сообщения проверяются только в объёме утверждённого [INTEGRATION_INTERFACE.md](../INTEGRATION_INTERFACE.md).
- Восстановление сети и разрешение полного автовозобновления — D-051. После перезагрузки ПР205/подтверждённого байпаса требуется новый «Пуск».
- Методики потери связи требуют детализации; проверки утверждённых функций ШОД добавлены ниже.
