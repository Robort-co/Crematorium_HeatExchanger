## Реализация

`simulator/src/shutter-test.mjs` формирует запросы теста и его результаты; `Protection` остаётся единственным отправителем команд. `engineering-cycle.mjs` управляет только переходами/результатами и вызывает существующие допуски механизмов.

| Сценарий | Поведение модели |
| --- | --- |
| Отдельный тест | Инженерный сеанс, выключенная печь как явная предпосылка, подтверждённый STOPPED/насосы OFF с новыми 000/ПЧ STOP; исходные реальные CLOSED DI. Профиль без охлаждения, чужая активная проверка/незавершённые ручные действия не обходятся. |
| Полный цикл | До движения — признак незавершённости и требование полного теста в памяти. OPEN → новые DI OPEN → снятие направлений → CLOSE → новые DI CLOSED → STOP направлениям → результат. Успех сохраняет разрешённое питание, снимает только требование полного теста ШТ. Пуск отдельный. |
| Диагностика | 67,5 с на каждый ход; исходный контакт должен сняться за N=5 с, настройка 1–10 с. Проверяется именно исходный контакт, в том числе при 1/1. Самостоятельная диагностика 1/1 — 5 с. Снятие направлений/питания, ошибка, блокировка и требование полного повтора. |
| Отказ/выход | FAILED; без автоматического реверса/повтора и без запроса байпаса по собственной инженерной неисправности. Поздние DI и выход из режима ошибку/требование не снимают. |
| Возврат питания | Отдельные подтверждения ремонта, окончания ручного вмешательства и зацепления; реальные CLOSED DI. Снимаются только ошибки/блокировка ШТ. Полный тест ещё обязателен. Ручное «закрыт» не заменяет DI. |
| Отмена/HMI | NOT_CHECKED; разрешённое закрытие, при уже CLOSED без нового движения. Закрытие, которое уже идёт, сохраняет исходный таймер. HMI — 5 с без дополнительной задержки; возврат связи не возобновляет попытку. |
| Низкое давление | В узко согласованном профиле — отмена с закрытием ШТ; OFF насосов/OPEN их затворов по давлению сохраняются. Нормализация не возобновляет тест. Если закрытие само отказало, FAILED/блокировка старше NOT_CHECKED. |
| Reboot | Память модели сохраняет требования, результат и историю. Незавершённая попытка становится NOT_CHECKED, инженерный режим выключен; никакое прежнее движение, включая закрытие после отмены, не продолжается. Новый вход/подготовка/полный тест отдельно. |
| D-265 | Две объединённые ветви D-251/D-252, затем ШТ. Каждый следующий тест ожидает отдельной команды. Повторный допуск и обязательные ручные возвраты проверяются сервером. Чужую проверку через отдельную кнопку нельзя запустить поверх активного общего цикла. |
| Пропуск/повтор/отмена | Пропуск только до начала теста, NOT_CHECKED без снятия требований. Выборочный повтор выполняется с начала; прежний успех этого теста перестаёт быть текущим, независимые результаты/точка продолжения сохраняются. Отмена активного теста идёт по его правилам, следующий сам не запускается. |
| Граница общего цикла | ШОД и дымосос остаются явными нереализованными этапами. «Продолжить» возвращает причину; пропуск помечается NOT_CHECKED. Завершение списка после пропусков не означает успешный общий цикл. |

HMI содержит отдельные органы теста/возврата ШТ, настройку N и управление общим циклом. Сервер повторно проверяет поколение/контекст и допуск. Самостоятельных аппаратных команд, Modbus-адресов и новых обязанностей ARANGA нет. Во время теста передаётся STOPPED, готовность 0; собственные ошибки доступны в существующем списке причин.

## Ограничения и точка продолжения

1. Реализовать профиль ШТ с охлаждением по уже утверждённым D-215–D-217 и D-163/D-084, включая достоверную циркуляцию до открытия и её потерю. Не повторять старый вопрос, уже закрытый D-217; новые неописанные сочетания уточнять отдельно.
2. Прочие сочетания теста с неизвестными давлениями, аварийным входом, потерей управления, сетью/температурой/ПЧ остаются явной паузой. Новое согласование низкого давления эти области не закрывает. Начальное положение ШТ для текущей полной попытки — CLOSED; автоматическая подготовка из иных положений этим этапом не добавлена.
3. Следующие независимые механизмы — ШОД по D-225–D-233, затем дымосос по последующим решениям, сохраняя D-265 и его отдельные переходы. Полный общий цикл не объявлять пройденным до их реализации.
4. Сохраняются прежние открытые профили reboot при 111/частичных/неизвестных фазах и неподтверждённых исходных положениях. Reboot из прерванного теста ШТ не закрывает его автоматически; текущий профиль восстановления STOPPED требует новых CLOSED DI.
5. **Настоящего энергонезависимого хранения нет**: снимок теряется с процессом Node.js; нет атомарной записи, испытаний повреждения/отключения питания. Временные признаки до команды — порядок операций в памяти имитатора. Не подтверждены WB 8.5, реальный I/O, Modbus, электрические схемы и физическая безопасность.
