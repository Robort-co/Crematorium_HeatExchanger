# Единая таблица состояний, переходов и приоритетов WB — 14.11.2026

Сводка утверждённых требований с учётом окончательных решений [D-322–D-335](2026-11-14_Итоги_сессии.md). Не заменяет детальные последовательности механизмов и не утверждает новые аварийные действия. Отменённые промежуточные варианты — [история](2026-11-14_Итоги_сессии.md#history). Реализация и испытания не выполнены.
Основных состояний четыре по [D-301](2026-11-13_Итоги_сессии.md#d-301): «Остановлен», «Запуск», «В работе», «Останов». Аварии, режим Ручной/ARANGA, инженерный режим и самостоятельное охлаждение — отдельные признаки/подпроцессы, не дополнительные основные состояния.

| В работе, ручной режим, попытка выбрать ARANGA | Переход во время работы запрещён. Сначала полный останов, выбор ARANGA, новый пуск только от ARANGA. | [D-329](2026-11-14_Итоги_сессии.md#d-329) |
| В работе, ARANGA, оператор выбирает ручной режим | По D-267 текущая выдаваемая частота становится ручным заданием; это не измеренные обороты. Само восстановление ARANGA ручной режим не отменяет. Нельзя отменить уже принятый обязательный останов. | [D-267](2026-11-10_Итоги_сессии.md#d-267), [D-329](2026-11-14_Итоги_сессии.md#d-329) |

| В работе, ARANGA, первая новая принятая запись частоты после восстановления | Возвратить управление ARANGA через LIMIT/резонанс, если нет более высокого приоритета и режим остаётся сквозным. Нового таймера частотных записей/нового Пуска нет. | [D-331](2026-11-14_Итоги_сессии.md#d-331) |
| Принят Стоп HMI/ARANGA | → Останов; обязателен с принятия, не отменяется новым Пуском, сменой режима или возвратом связи. Дымосос на частоте охлаждения по D-262. Пуск во время останова не ставится в очередь. | [D-262–D-264](2026-11-10_Итоги_сессии.md#d-262), [D-299](2026-11-13_Итоги_сессии.md#d-299) |
| Останов до подтверждения ШБ открыт | Запросить ручное открытие и ждать подтверждения. Не выдавать ложное Остановлен. | Останов, ШБ открыт подтверждён | Закрывать ШТ только при разрешениях движения/питания. Таймаут, концевики, неисправности и ручная процедура — по действующим правилам ШТ. | [D-315](2026-11-13_Итоги_сессии.md#d-315) |
| Нормальная последовательность после подтверждённого закрытия ШТ | Закрытие затвора рабочего насоса → насос OFF по закрытию или через 45 с; затем положения останова, по умолчанию открыты. По завершении → Остановлен; ошибки сохраняются. Это не замена особых отключающих защит/D-117. | [D-169](2026-11-05_Итоги_сессии.md#d-169), [D-318](2026-11-13_Итоги_сессии.md#d-318) |

Потеря подтверждения закрытия ШТ — по D-163; автоматического пуска насосов только ради такого охлаждения не добавлять. | [D-019](../DECISIONS.md); [D-163](2026-11-02_Итоги_сессии.md#d-163); [D-261](2026-11-10_Итоги_сессии.md#d-261) |
| Остановлен, инженерный режим | Готовность 0, причина Инженерный режим; механизмы могут проверяться отдельно при своих допусках. Общий порядок: ветвь 1 → ветвь 2 → ШТ → ШОД → дымосос. Ручные переходы/пропуски/повторы по принятым правилам. | [D-254](2026-11-10_Итоги_сессии.md#d-254)/[D-265](2026-11-10_Итоги_сессии.md#d-265), [D-253](2026-11-10_Итоги_сессии.md#d-253)/[D-255](2026-11-10_Итоги_сессии.md#d-255)/[D-256](2026-11-10_Итоги_сессии.md#d-256) |

## Доступность HMI и реакции

Условие D-332: хотя бы один интерфейс управления с подтверждённым обменом. Опциональная панель учитывается после подключения; сама работа веб-сервера не заменяет клиента. Через 5 с отсутствия всех таких интерфейсов:

| Область | Реакция | Основание |
| --- | --- | --- |
| Новый пуск | Запрещён, включая ARANGA; готовность 0, причина Нет связи с HMI. После восстановления нужны разрешения и новая команда. | [D-272](2026-11-10_Итоги_сессии.md#d-272) |
| Обычная ручная работа | Продолжать последнее ручное задание с защитами; не переключать автоматически на ARANGA. | [D-271](2026-11-10_Итоги_сессии.md#d-271) |
| Обычная сквозная работа | Продолжать управление ARANGA; при её потере тоже удерживать последнее действующее задание по D-330, без недоступной местной корректировки. | [D-274](2026-11-10_Итоги_сессии.md#d-274) с заменой рабочей реакции ARANGA по [D-330](2026-11-14_Итоги_сессии.md#d-330) |
| Запуск | Прервать по D-273; обе потери вместе — D-287. | [D-273](2026-11-10_Итоги_сессии.md#d-273)/[D-287](2026-11-11_Итоги_сессии.md#d-287) |
| Принятый останов | Не отменять; ждать ещё не полученных обязательных подтверждений. Потеря HMI не равна ШБ открыт. | [D-263](2026-11-10_Итоги_сессии.md#d-263)/[D-264](2026-11-10_Итоги_сессии.md#d-264)/[D-315](2026-11-13_Итоги_сессии.md#d-315) |
| Инженерная проверка | Прекратить незавершённый тест с действиями конкретного механизма и причиной потери HMI; инженерный режим/блокировки сохраняются, автоповтора нет. | [D-235](2026-11-10_Итоги_сессии.md#d-235) |

После возврата HMI отображается актуальное состояние, старые нажатия/значения не воспроизводятся. Действующие неисправности не стираются по самому факту подключения.

## Службы, надзор и восстановление

| Наблюдаемая часть | Кто контролирует / событие | Принятая реакция и граница |
| --- | --- | --- |
| Основная программа | Отдельный надзор: 2 с без завершённого рабочего цикла | Для работающего ТО — обязательный аварийный останов по [D-312](2026-11-13_Итоги_сессии.md#d-312)–[D-319](2026-11-13_Итоги_сессии.md#d-319), независимо от восстановления основной программы; NV-блокировка. |
| Надзор | Защитная служба: 2 с без нового завершённого цикла проверки | Критическая неисправность/запрет пуска; для работающего ТО при исправной защите — тот же обязательный останов, NV и отдельный сброс. [D-324](2026-11-14_Итоги_сессии.md#d-324)/[D-325](2026-11-14_Итоги_сессии.md#d-325). |
| Защитная служба | systemd: 2 с без завершённого цикла; аварийный выход без специального ожидания | [D-326](2026-11-14_Итоги_сессии.md#d-326)/[D-327](2026-11-14_Итоги_сессии.md#d-327): авария управления, доступная диагностика/запрос байпаса, перезапуск с единственным экземпляром; после проверки входов — аварийный останов, если ТО работал. Нет автоматического возврата в работу. |
| Защитная служба не исполняется | Нет гарантированного отправителя новых команд механизмам | Состояния выходов, сохранение циркуляции и возможность безопасного управления в промежутке открыты. Не задавать автоматически нули или удержание всех выходов. |
| ОС/весь WB недоступны | Общая точка отказа всех программных служб | Программный надзор на том же WB не считается аппаратной защитой. [D-321](2026-11-13_Итоги_сессии.md#d-321) — отдельная аппаратная задача пользователя, схема не подтверждена. Внутреннюю логику печи здесь не дополнять. |
| Отказ служб при запуске, останове, охлаждении или инженерном тесте | Стадии и действующие механизмы отличаются от обычной работы | Охват не завершён. Не переносить автоматически рабочую процедуру на все случаи; требуется отдельная привязка к уже принятым действиям/состояниям. |

Все 2 с — требования обнаружения. Это не измеренная гарантия и не суммарное время восстановления. Параметры/ограничения перезапусков и собственные общие отказы остаются открытыми.

## Утверждённые приоритеты (частичный порядок)

| Область | Принятый приоритет | Основание |
| --- | --- | --- |
| Пуск/Стоп | Стоп выше Пуска; повтор не сбрасывает таймеры; снятие команды/возврат связи не отменяет принятый останов. | [D-299](2026-11-13_Итоги_сессии.md#d-299)/[D-263](2026-11-10_Итоги_сессии.md#d-263) |
| Владение выходами | Защитная служба проверяет разрешения и выдаёт итог; основная программа не конкурирует за выходы после восстановления. | [D-323](2026-11-14_Итоги_сессии.md#d-323) |
| Насосы | Самостоятельная отключающая защита выше сохранения циркуляции до ШТ закрыт. Отказ программы не объявляется отказом обеих ветвей. | [D-313](2026-11-13_Итоги_сессии.md#d-313)/[D-314](2026-11-13_Итоги_сессии.md#d-314) |

Утрата ARANGA по D-330 сама не является остановом. | [D-262](2026-11-10_Итоги_сессии.md#d-262)/[D-316](2026-11-13_Итоги_сессии.md#d-316)/[D-330](2026-11-14_Итоги_сессии.md#d-330)/[D-331](2026-11-14_Итоги_сессии.md#d-331) |
