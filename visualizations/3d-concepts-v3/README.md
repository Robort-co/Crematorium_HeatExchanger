# Горизонтальная компоновка теплообменника — v3

15.11.2026. Продолжение выбранного варианта 1. Версии v1 и v2 сохранены отдельно.

## Изменения по указанию пользователя

- Верхний корпус продолжается **влево** через переход и короткий прямоугольный короб с ШТ (ШД в сообщениях пользователя).
- Далее газоход немного снижается к дымососу. ШОД сохраняется на врезке наружного воздуха перед дымососом.
- После дымососа горизонтальный участок входит в вертикальный дымоход. Газовая цепь стала шире и ниже для горизонтального экрана.
- Дымоход строго ориентирован по вертикальной оси Y. Ортографическая камера сохраняет вертикаль на экране без перспективного схождения линий.

В v2 цилиндр дымохода тоже имел вертикальную ось. Видимый наклон создавался перспективной проекцией при наклонённом вниз ракурсе. В v3 изменена камера, а не компенсирован наклон поворотом дымохода.

## Что соответствует CAD, а что изменено для эскиза

**Сохранено:** корпуса, 136 жаровых труб, перегородки, трубные доски, водяные патрубки, перемычка, опоры, камера переворота и их исходные координаты. Водяной контур не переделан и не соединён с новыми газоходами.

**Изменено только отображение газового выхода:** при включённой новой компоновке скрываются четыре сетки исходного канала STEP — индексы 218–221. Вместо них показывается новый боковой короб. Он **не является геометрией исходной сборки**. Это выполненное по просьбе пользователя художественное изменение для объяснения цепи.

Сам исходный STEP и файл всех импортированных сеток не редактировались. Отключите «Новая компоновка» — все новые детали исчезнут и четыре исходные детали выхода вверх снова появятся. По умолчанию 11 сеток прежней вынесенной группы остаются скрыты, как в v1/v2; есть отдельный переключатель.

## Условности

Направление выхода влево и небольшое снижение соответствуют новому указанию пользователя. **Численные длины, сечения, снижение, высота дымохода, форма коробов и соединений остаются параметрами рисунка**, а не проверенными размерами объекта. По эскизу нельзя изготовлять или монтировать обвязку.

Форма и основные условные размеры дымососа перенесены из v2; изменено его размещение. Это не CAD конкретного Д3,5. Форма и диаметр дымохода сохранены относительно v2, его условная высота уменьшена для более низкой композиции. Приводы, положения пластин ШТ/ШОД, количество лопаток и крепления не подтверждены. Соединения показаны визуально без проверки коллизий, булева объединения газовых полостей, прочности и сопротивления.

Статичные стрелки показывают только внешний маршрут газа и поступление наружного воздуха через ШОД. Направление газов внутри ярусов ТО не назначено. Отдельный дымоход байпаса с дымоходом ТО не объединяется.

## Открытие на Windows

Распакуйте весь ZIP и откройте `index.html` в Chrome или Edge. Файлы `viewer.js`, `model-data.js` и `style.css` должны оставаться рядом. Сервер, интернет и установленный Node.js для просмотра не нужны. Проверка выполнена в локальном Chrome; Edge отдельно не проверялся.

- Левая кнопка мыши — вращение, колесо — масштаб, правая — смещение обзора.
- Кнопки: общий вид, сбоку, с другой стороны, крупно ТО.
- Узлы выбираются щелчком или списком справа; происхождение и ограничения отображаются в карточке.
- Переключатель новой компоновки возвращает исходный CAD для сравнения.
- Список состояний — только ДЕМО-подсветка. Он не задаёт положения заслонок и не отправляет команды.
- PNG в `previews/` открываются без WebGL.

Для изменения исходника при установленном Node.js: `npm install`, затем `npm run build`. Повторный CAD-импорт выполняется отдельно и проверяет хеш исходного STEP.

## Проверка

В `verification.json` сохранены результаты локальной загрузки, выбор узлов, демонстрационное состояние, отключение новой компоновки и проверки подписей. Поля `chimneyWorldAxis` и `chimneyScreenDeltaX` проверяют вертикальность в координатах сцены и отсутствие горизонтального смещения оси на экране. Поля `sourceOutletVisible` подтверждают скрытие четырёх деталей прежнего выхода при новой компоновке и их возврат при её отключении.

Программа, защиты, межсистемный обмен, электрические схемы и существующий HMI не изменяются. Подключений к оборудованию и симулятору нет. Готовая v3 сохранена в результатах текущей задачи.
