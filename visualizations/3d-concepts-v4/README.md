# Компоновка мнемосхемы v4

15.11.2026. Отдельное продолжение v3 по новому указанию пользователя. Программа, электрическая схема, действующий HMI и технологические алгоритмы не изменялись. Это автономный демонстрационный просмотрщик без подключения к оборудованию.

## Что изменено

- Выход верхнего корпуса и ШТ сохранены по v3. После них газоход поворачивает **направо на 90° в плане по ходу газа**. За отводом расположены ШОД, дымосос и отдельный вертикальный дымоход ТО.
- К нижнему корпусу добавлен **соосный входящий газовый тракт**. Открытый край с волнистой линией и пунктиром обозначает обрыв изображения в сторону печи ARANGA, а не заглушку. Печь не моделировалась.
- Для небольшого поворота по часовой стрелке выбран **эскизный угол 12° при взгляде сверху**. Этот угол не задан пользователем численно и не является монтажным размером. Вся сборка вместе с присоединёнными трактами повёрнута как единое целое, поэтому соединения сохраняются.
- Добавлен ракурс **«Сверху · 90°»**, обновлены подписи и карточки узлов.

Основание — прямое указание пользователя в текущем чате: оставить примерную компоновку, немного повернуть теплообменник, выполнить поворот тракта направо на 90° по ходу газов, расположить за ним дымосос и дымовую трубу, добавить осевой вход к нижнему корпусу с обрывом в сторону печи ARANGA. Исполнение v4 после просмотра ещё не подтверждено.

## Как открыть

Открыть [index.html](index.html) в локальном браузере с WebGL. Соседние viewer.js, model-data.js и style.css необходимы. Для просмотра не нужны сервер, интернет и Node.js.

- Левая кнопка мыши — вращение, колесо — масштаб, правая — смещение.
- «Сверху · 90°» показывает правый поворот в плане.
- Узел выбирается щелчком или списком справа.
- «Новая компоновка» выключает условные входящий и выходящий тракты и возвращает четыре исходные детали выхода CAD. Разворот сборки остаётся тем же.
- «Показать состояние» меняет только демонстрационную подсветку.
- [Схема плана](previews/plan.png) — отдельная иллюстрация, рассчитанная из той же геометрии. Это **не снимок браузера и не рендер полной CAD-сборки**. В виде сверху нижний вход частично перекрывается верхним выходом; вход отмечен прерывистой линией.

## Геометрия и допущения

В локальных координатах сборки Y направлена вверх. Газ выходит из верхнего корпуса вдоль −X. Правая сторона по ходу этого потока — −Z; ось после отвода направлена вдоль −Z. Отвод задан аналитической четвертью окружности. Общий разворот вокруг Y не меняет угла и стороны поворота.

Ось входящего тракта совпадает с осью нижнего CAD-корпуса: Y = 0,575 и Z = 0 в системе координат просмотрщика. Это координаты преобразованной модели, не новые проектные отметки. Переход и длина входящего участка — художественное дополнение.

Исходный STEP, model-data.js и cad-audit.json совпадают с v3. Все 247 исходных сеток загружаются; по прежнему правилу четыре детали выхода вверх 218–221 скрыты при новой компоновке, 11 вынесенных деталей доступны отдельным переключателем. Новые элементы имеют origin: concept.

Форма, длины, сечения, радиус отвода, снижение, крепления, форма дымососа и показанные положения ШТ/ШОД остаются условными. Проверка монтажных коллизий, газовых полостей, прочности и сопротивления не выполнялась. Водяной контур сохранён. Внутренние газовые стрелки не добавлены. Отдельный дымоход байпаса не объединён с дымоходом ТО.

## Проверка

[verification.json](verification.json) содержит результаты проверки исходников и геометрии: направление правого поворота, угол между касательными, совпадение концов отвода и газохода, присоединение к входу дымососа, осевой вход нижнего корпуса и вертикальность дымохода. Проверены сборка, синтаксис и наличие используемых идентификаторов HTML.

Новая проверка WebGL и взаимодействий **не выполнена**: открытие file:// заблокировано политикой браузерного инструмента. Обход ограничения не предпринимался. PNG плана проверен визуально отдельно; он не подтверждает работу браузерного просмотрщика.

Все 21 файла v3, включая PROJECT_STATUS.md, сверены с [исходным списком SHA256](source-v3-manifest.json) и не изменены. Исторические протоколы и старые PNG из v3 в v4 не копировались. Записи этапа ограничены папкой visualizations/3d-concepts-v4/. Commit/push не выполнялись.

## Редактирование и сборка

- src/gas-concept.js — условные входящий и выходящий тракты; conceptNotes хранит параметры эскиза.
- src/viewer.js — сцена, общий разворот, ракурсы и подписи.
- index.html, style.css — интерфейс просмотрщика.
- npm ci, затем npm run build — сборка при наличии Node.js. Версии зависимостей закреплены package-lock.json; node_modules и .npm-cache исключены через локальный .gitignore.
- node src/export-plan.mjs, затем python src/render-plan.py — обновление схемы плана. Python-скрипту нужны Pillow и шрифты Segoe UI на Windows.

PROJECT_CONTEXT.md и INTEGRATION_INTERFACE.md этим этапом не менялись: внешний обмен, оборудование, архитектура управления и режимы работы не затронуты. Оформление ARANGA не применялось.
