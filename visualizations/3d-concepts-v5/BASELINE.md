# Фиксация v5 как основы

Дата решения: 15.11.2026.

Основание — прямое сообщение пользователя после показа v5: «Фиксируем этот вариант. В принципе, там много полезного, давай его зафиксируем и уже на его основе сделаем ещё изменения ремарки».

## Принятый статус

**v5 на основе v2 принята как текущая визуальная основа для дальнейших правок.** Геометрия, оформление, исходники просмотрщика и изображения при фиксации не менялись; добавлены только документы статуса и контрольный архив.

Зафиксированы квадратный короб с сужением обеих сторон, ШТ после сужения, арочная верхушка с общим центром круглого патрубка, соосный дымосос над ТО, верхний выпуск налево и вертикальный дымоход. ШОД в этой версии отсутствует по последнему прямому указанию пользователя.

Точные числа в макете остаются параметрами рисунка. Принятие варианта не подтверждает монтажные размеры, расчёты, готовность к изготовлению или работу оборудования. Ранее описанные ограничения браузерной проверки сохраняются.

## Сохранение

- Рабочий просмотр: [index.html](index.html).
- Контрольный архив: [heat-exchanger-v5.zip](../baselines/2026-11-15-v5/heat-exchanger-v5.zip).
- Контрольные суммы: [MANIFEST.sha256](../baselines/2026-11-15-v5/MANIFEST.sha256).
- Протокол сверки архива: [CHECKPOINT.json](../baselines/2026-11-15-v5/CHECKPOINT.json).

Архив содержит готовый просмотрщик, исходники, STEP, данные модели, PNG и документацию. node_modules, кэш npm и промежуточный scene-data.json не включены. Установка зависимостей для открытия готового index.html не требуется.

## Продолжение

Следующую итерацию создавать отдельно как v6 на основе зафиксированной v5. Конкретные новые ремарки пока не заданы. v5 и прежние версии не перезаписывать при реализации последующих правок.

Фиксация локальная, без commit/push. Программа установки, действующий HMI, электрическая схема, защиты и межсистемные интерфейсы не менялись.
