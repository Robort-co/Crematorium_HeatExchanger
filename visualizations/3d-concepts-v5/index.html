Газовый тракт

Верхняя банка → вверх → квадратное сужение → ШТ → арочная камера → обратно вдоль банок → дымосос → верхний выпуск налево → дымоход

Направление «налево» задано по ходу входящего в дымосос газа. Дымоход байпаса остаётся отдельным.

Водяной контур · сохранён

Обратка → насосная группа → нижний корпус → перемычка → верхний корпус → подача

Внешняя водяная обвязка и приборы не добавлены. Ориентация исходной сборки — как в v2.
Из STEP: корпуса, трубы, перегородки, патрубки, опоры и камера переворота. Новая геометрия: выходной короб, сужение, ШТ, арка, короткий патрубок, улитка и дымоход. Четыре исходные детали выхода скрыты при включённой новой обвязке. Условно: размеры, приводы и крепления. Это компоновка для просмотра, не монтажный чертёж.
