15.11.2026, Europe/Moscow. Эскизы для выбора стиля. Ни один вариант ещё не согласован.

## Просмотр на Windows

Распакуйте весь архив в одну папку и откройте `index.html` двойным щелчком через Chrome или Edge. Рядом должны оставаться `style.css`, `viewer.js` и `model-data.js`. Интернет, Node.js, сервер и симулятор для просмотра не нужны. Проверено в установленном Chrome на Windows через локальный адрес `file:///`; Edge отдельно не проверялся.

- Кнопки 01–03 меняют стиль одной и той же геометрии.
- Левая кнопка мыши — вращение; колесо — приближение; правая кнопка — смещение обзора. Доступны три фиксированных ракурса.
- Узел выбирается щелчком по модели или в списке. В непрозрачном режиме внутренние детали остаются скрыты корпусом: для их осмотра включите стиль 01 или 02.
- Список состояний меняет только подпись и подсветку выбранного узла. Все состояния — ДЕМО. Числовых технологических показаний нет. Схемные элементы без CAD имеют текстовую карточку, но не геометрическую подсветку.
- «Вынесенная группа STEP» показывает 11 сеток группы «Крепление трубы» в исходных координатах; по умолчанию они скрыты.
- Если WebGL недоступен, используйте PNG в `previews/`.

**Отличие от картинки:** PNG содержит один фиксированный ракурс. Просмотрщик строит сцену из отдельных треугольных сеток: её можно вращать, приближать, менять материалы и выделять узлы. Это не CAD-редактор, не расчёт течения или прочности и не работающая HMI.

## Варианты и их назначение

| Вариант | Оформление | Применение и ограничение |
| --- | --- | --- |
| 01. Полупрозрачный | Полупрозрачные оболочки, сдержанные акценты труб и водяных патрубков | Одновременный обзор корпуса и внутреннего устройства; наложение поверхностей усложняет чтение плотных участков |
| 02. Технический разрез | Передняя часть оболочек скрыта плоскостью; внутренние детали сохранены | Лучше видно трубные пучки и перегородки; это условный графический разрез без оформления по ЕСКД |
| 03. Промышленный | Непрозрачный металл, свет и подсветка выбранного узла | Подходит для внешнего обзора и состояния оборудования; внутренности скрыты. Материалы синтетические, это не фотография фактической установки |

Рекомендация для обсуждения: 01 — кандидат для общего обзора, 02 — для объяснения устройства, 03 — для внешнего операторского представления. Это оценка удобства, а не утверждённое решение. Выбирать и дорабатывать можно по одному варианту.

## Условности и ограничения

- Цвета, материалы, шероховатость, освещение, прозрачность, ракурсы и плоскость разреза — новые художественные предложения. Шероховатость и отражения не взяты из паспортов материалов.
- Все исходные координаты сохранены с общим поворотом и переносом для удобства просмотра: `(x,y,z) CAD, мм → ((z+980)/1000,(y+575)/1000,-x/1000), м`. Детали не переставлялись.
- Для сечения отключена видимость части поверхности оболочек и камеры; новые физические стенки или заглушки сечения не строились. Внутренние детали не пересчитывались.
- Насосов, фильтров, приводных насосных затворов, ШТ, ШОД и дымососа в импортированном дереве не найдено. Их состав и порядок представлены отдельно как функциональные связи; размеры, точные координаты и трассы не придуманы. ШБ/эжектор показаны только как отдельная ветвь, без общей трубы с выходом ТО.
- Направление газа через нижний/верхний ярус не считается подтверждённым: стрелок внутри 3D-модели нет. Указан подтверждённый функциональный путь за пределами ТО. Водяная схема показывает штатное направление, а не все аварийные/обратные режимы.
- Место TUF-2000B не подтверждено; расходомер не поставлен на произвольно выбранную трубу. Датчики давления и температуры не размещены в точных 3D-координатах.
- Клапан в CAD идентифицирован по имени сборки «1-Клапан 17с28нж в сборе». Фактическая комплектация, настройка и работоспособность не проверены.
- Вынесенная группа «Крепление трубы» не присоединена к газоходу. Назначение её исходного разрыва требует уточнения.
- Модель полигональная, без истории параметрического построения. Качество импорта не является полной проверкой тел CAD, коллизий, зазоров, технологичности или прочности. Общий габарит включает вынесенную группу и не используется как габарит установки.
- Производительность проверена только на доступном настольном Chrome. Работа на планшете, встроенной панели и WB не подтверждена. Для HMI потребуется отдельная оптимизация сеток и согласование цветовой семантики.

Для разработки при установленном Node.js: `npm install`, затем `npm run build`. Повторный импорт исходного STEP — `npm run import-cad`. Установка зависимостей требует сети; просмотр готовой версии — нет. Импорт проверяет SHA256 и число сеток, чтобы не перенести старую привязку индексов на новую CAD-сборку без проверки. Изменение модели требует отдельной проверки привязки деталей.

Проверены отсутствие ошибок JavaScript и внешних HTTP(S)-запросов. Кадры всех трёх стилей осмотрены. К существующим `simulator/`, `simulator/web/`, `docs/schemes/`, `visualizations/hmi-concept-v1/` и основным документам запись из этой работы не выполнялась. Защиты, алгоритмы, Modbus и интерфейсы не изменены; к оборудованию и симулятору соединений нет. Дальнейшее изменение геометрии или оформления выполняется после выбора, отдельной версией с сохранением остальных элементов.
