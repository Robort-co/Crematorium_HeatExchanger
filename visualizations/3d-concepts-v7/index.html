Отключение новой обвязки возвращает исходный CAD. «Арка крупно» скрывает дымосос; «Общий вид» возвращает его. «Скосы крупно» показывает задние наклонные торцы. «Насосы крупно» показывает обе ветви.

Газовый тракт

Верхняя банка → закруглённый низ короба → вверх → сужение → ШТ → арка → круглая труба поперёк банок → дымосос → вверх → переход → дымовая труба

Новая ось круглого тракта совпадает с направлением выпуска дымососа в v5. Дымоход байпаса остаётся отдельным.

Две параллельные насосные ветви

В каждой: ручной кран → фильтр → насос → электрозатвор → ручной кран → отвод в ТО. Поток по обратке направлен сверху вниз.

Состав — по утверждённой гидравлике. Форма оборудования и расстояния условны; текущие состояния неизвестны.
Из STEP: корпуса, трубы, перегородки, патрубки, опоры и камера переворота. Изменения v7: два плоских скоса задних торцов по образцу STEP и две насосные ветви вместо прямого участка обратки. Условно: размеры новой обвязки, насосы, фильтры, краны и приводы. Н1/Н2 обозначают ветви, а не фактическое состояние. Это компоновка для просмотра, не монтажный чертёж.
