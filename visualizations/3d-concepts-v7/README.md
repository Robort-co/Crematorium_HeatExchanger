# Мнемосхема v7 — скосы короба и насосные ветви

15.11.2026. **Пользователь принял v7 как основу для дальнейших правок.** Версия на основе v6 зафиксирована отдельным локальным архивом с SHA256. Следующие изменения выполнять отдельно в v8 на основе v7. Прежние версии сохранены без изменений. [Запись фиксации и границы согласования](BASELINE.md).

## Просмотр

[index.html](index.html) — готовая автономная сборка. Рядом должны находиться viewer.js, model-data.js и style.css.

- «Скосы крупно» показывает обе задние наклонные грани короба до и после ШТ.
- «Насосы крупно» показывает две параллельные ветви на обратке.
- «Обратка воды» показывает группу и соединение с перенесённым фланцем.
- Отключение новой обвязки возвращает исходный CAD, включая прямую трубу обратки. Демонстрационные состояния меняют только подсветку; команд оборудованию нет.

## Прямые требования пользователя

Пользователь подтвердил два стыка на задней стороне короба: нижний перед ШТ и верхний после ШТ; тип изменения — **прямые наклонные грани**. В качестве образца указана деталь исходной STEP-модели над теплообменником, где закруглённая оболочка сопряжена с наклонным полукруглым торцом.

Дополнительно пользователь поручил изобразить насосные группы на трубе обратки. Это дополнение к правке скосов, а не отмена предыдущего поручения.

## Скосы по STEP

Найден исходный элемент 219 «Выходной канал торец полукруглый» в узле 218–221. Его большая полукруглая грань — плоскость, наклонённая относительно прямой задней стенки. Численно извлечённое отношение смещения к высоте — около 0,48135, угол от вертикали — около 25,70°. Измерение выполнено по треугольникам импортированной STEP-геометрии, поэтому это приближённые данные модели.

[step-bevel-reference.json](step-bevel-reference.json) содержит источник, SHA256 исходного STEP, нормаль и наклон. В v7 этот наклон применён к обоим задним полукруглым торцам: нижний скошен внутрь при движении вниз, верхний — при движении вверх. Круглые оболочки подрезаны по этим плоскостям. Прямоугольные задние стенки, сужение, положение ШТ, отверстия и оси труб сохранены.

Это изменение формы эскиза по образцу. Оно не добавляет монтажных размеров, толщины листа, требований к сварке или расчёта сопротивления.

## Насосные ветви

Состав взят из [утверждённой гидравлики от 29.10.2026](../../docs/2026-10-29_Утверждённая_гидравлика.md), D-124, D-131–D-133, с подтверждением общей схемы D-007:

**В каждой из двух параллельных ветвей по штатному потоку: ручной шаровой кран → фильтр → насос → электроприводной затвор → ручной кран.**

Документы называют два одинаковых ROMMER FORCE65-140F380V. В этой визуализации они обозначены Н1/Н2 и показаны условной геометрией, без утверждения соответствия корпусам производителя. Обычно один рабочий, второй резервный; фактическое состояние обоих здесь неизвестно. Обратных клапанов нет по действующей схеме, прямого обхода насосов не добавлено.

Компоновочное допущение v7: группа размещена на месте прямого вертикального участка перенесённой обратки, между теми же точками подключения. Поток идёт сверху вниз. Коллекторы, расстояние между ветвями, размеры условных корпусов, фильтров, приводов и кранов выбраны только для читаемости мнемосхемы. Установка реального оборудования в этот габарит не проверена. Датчики давления и внешние трубопроводы этим этапом не моделировались.

Прямую трубу CAD 19 скрываем только при показе новой обвязки. Отвод, существующие фланцы, их перенос из v6 и крышка старого подключения сохранены. Исходные STEP и model-data.js не редактируются; исходная труба остаётся доступной при отключении макета.

## Сохранность и проверки

Сборка `npm run build` прошла. [verification.json](verification.json) содержит 19 проверок, включая:

- сохранность всех 26 файлов контрольной v6, её ZIP и ранее сохранённых версий;
- неизменность исходного CAD, газовых проёмов и расположения остальных узлов;
- плоскостность обеих наклонных граней, соответствие наклону STEP и совпадение их кромок с круглыми оболочками;
- две одинаковые насосные ветви, порядок пяти устройств в каждой, примыкание прямых участков к портам;
- отсутствие прямого обхода насосов и возврат исходного CAD при отключении обвязки;
- конечность координат и наличие элементов интерфейса.

В сцене сохранены все 247 исходных сеток. При показе v7 видны 231 исходная сетка и 138 сеток новой обвязки. Скрыты 11 вынесенных деталей, прежний газовый выход 218–221 и заменённая в отображении прямая труба 19.

Предпросмотры общего вида, скосов, насосов, обратки и образца STEP просмотрены. Проверка WebGL и взаимодействий в браузере не выполнялась; сохранённое ограничение инструмента на file:// не обходилось. Прочность, гидравлическое сопротивление, обслуживание, крепления и полный поиск монтажных коллизий не проверялись.

## Исходники

- src/gas-concept.js — газовая обвязка, включая два скоса.
- src/pump-group.js — две насосные ветви и условные изображения оборудования.
- src/water-relocation.js — сохранённый перенос обратки из v6.
- src/assembly.js — общая сцена для просмотрщика и статичных изображений.
- src/viewer.js — подписи, подсветка и виды.
- `node src/verify.mjs` — проверки.
- `node src/export-preview.mjs`, затем `python src/render-preview.py` — рендеры; нужны NumPy, Pillow и Segoe UI. Промежуточные JSON исключены из Git.

Изменения ограничены v7 и журналом визуальных решений. Программа установки, электрическая схема, архитектура, алгоритмы защиты и межсистемный обмен не менялись. Commit/push не выполнялись.
