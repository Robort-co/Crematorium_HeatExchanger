# Решения по визуализации теплообменника

Этот журнал относится к автономным визуальным макетам. Он не изменяет технологические решения DECISIONS.md в корне проекта.

**Текущая принятая основа — [v7](3d-concepts-v7/index.html). Следующая итерация — v8; v1–v7 сохраняются.** Более ранние записи ниже отражают последовательность решений.

## 15.11.2026 — v5 принята как основа

Пользователь после показа v5 поручил: «Фиксируем этот вариант» и далее вносить изменения на его основе.

- Текущая основа: [v5](3d-concepts-v5/index.html), созданная из v2.
- Состав: сужающийся квадратный короб, ШТ, концентричная арка и круглый патрубок, дымосос над ТО, верхний выпуск налево, отдельный вертикальный дымоход.
- ШОД исключён из текущей версии; автоматически возвращать его в следующей итерации не следует.
- Фиксация: [BASELINE.md](3d-concepts-v5/BASELINE.md), [контрольный ZIP](baselines/2026-11-15-v5/heat-exchanger-v5.zip).
- Продолжение: новая v6 на основе v5 после получения конкретных ремарок. Прежние варианты сохраняются.
- Согласование относится к визуальной основе. Численные размеры, конструктивное исполнение и инженерные проверки остаются в статусе, указанном в README v5.

Программа и электрическая схема вне области этих изменений. Commit/push не выполнялись.

## 15.11.2026 — v6 по уточнениям пользователя

Подготовлена отдельная [v6](3d-concepts-v6/index.html) на основе принятой v5:

- низ газового короба закруглён соосно верхней банке;
- верхняя арка и круглый выход повёрнуты на 90° в прежнем направлении выпуска дымососа v5;
- круглый участок продлён, дымосос стоит на его конце, выпуск вверх через переход в круглую дымовую трубу;
- диаметр дымовой трубы условно уменьшен;
- по прямому уточнению переносится **водяная обратка** с отводом и вертикальной трубой на противоположный свободный фланец между банками; старый фланец заглушён;
- ШОД остаётся исключённым.

Численные параметры новой геометрии — допущения макета, не инженерные размеры. На момент подготовки v6 была представлена для просмотра; последующее принятие записано ниже. Основа v5 и её архив не изменены, сохранность подтверждена SHA256. Подробности и ограничения — [README v6](3d-concepts-v6/README.md).

## 15.11.2026 — v7: скосы и насосная группа

По прямому поручению пользователя подготовлены оба плоских скоса задних полукруглых торцов короба, перед ШТ и после ШТ. Образец — элемент 219 «Выходной канал торец полукруглый» из исходной STEP-модели. Наклон извлечён из геометрии; подробности в [README v7](3d-concepts-v7/README.md).

Дополнительным поручением пользователь запросил изображение насосных групп на обратке. Показаны две параллельные ветви по уже утверждённой гидравлике: ручной кран → фильтр → насос → электрозатвор → ручной кран. Пространственное размещение и форма оборудования условны для мнемосхемы; это не изменение утверждённой гидравлической схемы.

На момент подготовки v7 была представлена для просмотра; последующее принятие записано ниже. Зафиксированная v6 и предыдущие версии сохранены без изменений. Программа установки и электрическая схема вне области работ.
